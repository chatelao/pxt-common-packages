# Zigbee 3.0 (IEEE 802.15.4) for ESP32-C6

Provides Zigbee 3.0 mesh networking (`zigbee.startNetwork`), board-to-board Zigbee intercomm (`zigbee.sendString`, `zigbee.sendValue`, `zigbee.onReceivedString`, `zigbee.onReceivedValue`), and standard Home Automation ZCL endpoints (`zigbee.setSwitch`, `zigbee.onSwitchChanged`, `zigbee.reportTemperature`).
